# IBM_PROJECT
🏋️ FitLog

A dark-themed workout tracker that lets you log your training and visualize your consistency with a GitHub-style activity heatmap. Built as part of the IBM SkillsBuild internship project requirement.

🔗 Live Demo: ibm-project-ten-nu.vercel.app

🚀 Technologies Used
HTML5
CSS3
JavaScript (Vanilla)
Vercel (Deployment)
✨ Features
Workout logging
GitHub-style activity heatmap
Clean dark UI
Lightweight, no frameworks or build step
Deployed and publicly accessible
📚 What I Learned
Building a complete app using plain HTML, CSS, and JavaScript.
JavaScript DOM manipulation.
Rendering a data-driven heatmap from scratch.
Designing a consistent dark theme.
Deploying a project to production using Vercel.
Improving frontend development skills.
🎯 About the Project

This project was developed as part of the IBM SkillsBuild internship. It helped me strengthen my frontend fundamentals by building a practical, real-world fitness tracker without relying on any framework. It improved my understanding of DOM manipulation, UI design, and deploying a project end to end.
